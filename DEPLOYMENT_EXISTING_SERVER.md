# Развертывание на существующем сервере

## Ваша ситуация:
- Сервер: Timeweb Cloud (5.44.47.67)
- Уже работает: Docker + Portainer (порт 9443) + WireGuard
- Нужно: Добавить ShotShare Bot без конфликтов

## Стратегия безопасного развертывания:

### 1. Использовать отдельные имена контейнеров
### 2. Использовать отдельные порты
### 3. Использовать отдельную сеть Docker (опционально)
### 4. Не трогать существующие сервисы

---

## Шаг 1: Подготовка на сервере

### Проверка текущих контейнеров:
```bash
docker ps -a
docker network ls
```

### Проверка занятых портов:
```bash
netstat -tulpn | grep LISTEN
# или
ss -tulpn | grep LISTEN
```

---

## Шаг 2: Изменение конфигурации проекта

### Изменения в docker-compose.yml:

1. **Изменить имена контейнеров** (добавить префикс `shotshare_`)
2. **Изменить порт админки** (с 5000 на другой, например 5001)
3. **Изменить порт PostgreSQL** (с 5432 на другой, например 5433)
4. **Использовать отдельную сеть** (опционально)

---

## Шаг 3: Настройка портов

**Рекомендуемые порты:**
- Админка: `5001` (вместо 5000)
- PostgreSQL: `5433` (вместо 5432, если нужен внешний доступ)
- Бот: не требует портов (использует polling)

**Проверка свободных портов:**
```bash
# Проверить, свободен ли порт 5001
netstat -tulpn | grep 5001

# Проверить, свободен ли порт 5433
netstat -tulpn | grep 5433
```

---

## Шаг 4: Изменение docker-compose.yml

Нужно изменить:
- `container_name` - добавить префикс
- `ports` - изменить порты
- `volumes` - убедиться, что пути не конфликтуют

---

## Шаг 5: Развертывание

1. Загрузить проект на сервер
2. Настроить `.env`
3. Запустить через `docker-compose up -d`
4. Проверить, что все работает

---

## Важные моменты:

✅ **Безопасно:**
- Отдельные имена контейнеров
- Отдельные порты
- Отдельные volumes (если нужно)
- Не трогаем существующие контейнеры

⚠️ **Осторожно:**
- Проверить, не заняты ли порты
- Проверить, не конфликтуют ли имена
- Проверить, достаточно ли ресурсов

---

## После развертывания:

- Админка будет доступна по: `http://5.44.47.67:5001`
- Portainer останется на: `https://5.44.47.67:9443`
- WireGuard продолжит работать как раньше
