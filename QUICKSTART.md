# Быстрый старт ShotShare Bot

## Шаг 1: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен - он понадобится для настройки

## Шаг 2: Получение вашего Telegram ID

1. Найдите [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте команду `/start`
3. Скопируйте ваш ID (число)

## Шаг 3: Настройка проекта

1. Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. Откройте `.env` и заполните:
   - `TELEGRAM_BOT_TOKEN` - токен от BotFather
   - `ADMIN_USER_IDS` - ваш Telegram ID (можно несколько через запятую)
   - `ADMIN_SECRET_KEY` - сгенерируйте случайную строку:
     ```bash
     python -c "import secrets; print(secrets.token_hex(32))"
     ```
   - `ADMIN_PASSWORD` - придумайте пароль для админки

## Шаг 4: Запуск

```bash
docker-compose up -d
```

Проверьте логи:
```bash
docker-compose logs -f bot
```

## Шаг 5: Первое задание

1. Откройте админку: http://localhost:5000
2. Войдите с логином `admin` и вашим паролем
3. Перейдите в раздел "Задания"
4. Создайте новое задание:
   - Введите текст задания
   - Выберите дату и время отправки (можно поставить на ближайшие минуты для теста)
5. Сохраните задание

## Шаг 6: Тестирование бота

1. Найдите вашего бота в Telegram (по имени, которое вы указали при создании)
2. Отправьте команду `/start`
3. Отправьте команду `/register`
4. Следуйте инструкциям регистрации
5. Дождитесь задания (или создайте задание на текущее время)
6. Отправьте фото или видео (до 10 секунд)

## Проверка работы

- Бот должен принять контент
- В админке в разделе "Модерация" должен появиться пост
- После автоматического одобрения пост будет распределен другим пользователям

## Остановка

```bash
docker-compose down
```

## Полезные команды

Просмотр логов бота:
```bash
docker-compose logs -f bot
```

Просмотр логов админки:
```bash
docker-compose logs -f admin
```

Перезапуск сервисов:
```bash
docker-compose restart bot admin
```
